# Acceptance

AC1: Dated quote age, selected-position execution estimates, mid/natural basis and
held costs are available. Refresh preserves legs, held costs and thesis; missing
contracts or stale responses preserve current work.
AC2: Reuse assignment/contract terms, probability and supporting risk information.
Keep scenario P/L distinct from quote P/L, and expiry bounds from funding needs.
AC3: Reuse sourced context and existing validated conversation/proposal workflow.
Never execute model output directly. No prompt/tool changes in this migration.
AC4: Preserve existing root Undo, durable save and strategy/market search workflow
without breaking thesis isolation or widening prototype pricing assumptions.
AC5: Compact desktop/mobile layout, focused regression checks and independent
review. Commit checked pieces to the existing product branch; no deployment.

All presentation, validation, pricing and persistence are deterministic. Only
existing conversational synthesis is probabilistic. No added agent loop.
