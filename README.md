# ARGUS

Planning handoff for a paper-only options research system built for the Alpaca
hackathon. The product question is narrow: **when does AI add value over the
exact same deterministic options strategy?**

ARGUS tests whether a bounded AI selector or abstainer improves an otherwise
identical quant control after transaction costs. The literature motivates the
features and validation design; it does not validate ARGUS or prove AI alpha.

- [Specification](docs/SPEC.md): product scope, invariants, data and evidence contracts.
- [Implementation plan](docs/PLAN.md): milestones, acceptance checks, and handoff order.
- [Thesis](docs/THESIS.md): hypotheses, mechanisms, predictions, and claim boundary.
- [Validation protocol](docs/VALIDATION.md): paired evaluation and promotion rules.
- [App contract](docs/APP.md): evidence-first dashboard and demo flow.
- [Research basis](docs/RESEARCH.md): primary literature mapped to design choices.
- [Architecture decisions](docs/DECISIONS.md): deliberately small technical choices.

No source code, dependencies, secrets, or paper orders are included in this
planning milestone.
